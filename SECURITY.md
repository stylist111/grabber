# Безопасность

## Как сообщить об уязвимости

Пожалуйста, **не создавайте публичный issue** для проблем безопасности. Используйте закрытую форму GitHub:
**Security → Report a vulnerability** в этом репозитории. Ответ придёт в течение нескольких дней.

## Как проверить скачанный установщик

Официальные установщики публикуются только на странице [Releases](../../releases) этого репозитория. Каждый
собирается GitHub Actions из исходников с тегом и выходит с контрольной суммой SHA-256 и подписанным подтверждением
происхождения сборки:

```powershell
gh attestation verify Grabber-Setup.exe --repo stylist111/grabber
Get-FileHash Grabber-Setup.exe   # должна совпасть с SHA256SUMS.txt из того же релиза
```

Если проверка не проходит — не запускайте файл.

## Что может помощник

`grabber_host.exe` запускается браузером через native messaging и принимает сообщения только от расширения с ID
этого проекта. Он запускает yt-dlp и ffmpeg для обычных ссылок `http(s)` (они передаются после `--`, поэтому их нельзя
выдать за параметры), открывает Проводник с папкой загрузок, показывает окно выбора папки и обновляет yt-dlp с его
официальной страницы на GitHub. Он не открывает сетевых портов и ничего не хранит, кроме локального лога рядом с программой.
